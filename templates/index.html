UCS321 Unit 2: Data Preprocessing Protocol

  • Missing Values: Imputed 91 missing entries in parental_education_level using mode, and continuous features using median.
  • Target Leakage Prevention: Excluded total_score to build an authentic Early Warning System.
  • Normalization: StandardScaler ($\mu=0, \sigma=1$) strictly fitted on training split ($N=799$).
  • Feature Engineering: Digital distraction screen time, study-to-distraction ratio, and academic composite index.

UCS321 Unit 3: Random Forest Ensemble Architecture

  • Bootstrap Aggregation (Bagging): Trains $B=50$ independent decision trees on bootstrap random samples with replacement.
  • Random Feature Subsets: Samples $m \approx \sqrt{p}$ features at each split to decorrelate individual trees.
  • Out-of-Bag (OOB) Estimation: Uses out-of-bag samples (~37% of data per tree) to estimate generalization error without a separate validation set.
  • Hyperparameter Tuning: Optimized via GridSearchCV over max_depth, min_samples_split, and criterion.
